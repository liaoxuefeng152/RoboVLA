============================================================
RoboVLA V2.0 操作工快速上手指南
============================================================

## 第一步：开机

1. 按下 Jetson 边缘盒电源键，等待 2 分钟系统启动
2. 开机后上位机自动启动，显示主界面
3. 确认右上角显示"机器人已连接"和"授权正常"

## 第二步：拖拽示教（最重要）

1. 点击左侧菜单栏「示教模式」
2. 按下机械臂上的蓝色拖拽按钮，手臂进入自由拖拽状态
3. 手动拖拽机械臂完成一次完整的装配动作
   - 取料 → 移动到位 → 装配 → 松开
4. 完成后点击「停止录制」
5. 给任务起个名字（如："螺丝锁付-1号工位"），点「保存」

## 第三步：一键训练

1. 点击左侧菜单「AI 训练」
2. 选中刚录好的任务
3. 点击「开始训练」按钮
4. 等待约 5 分钟，进度条走完即可
5. 看到"训练完成，可以开始生产"绿色提示

## 第四步：自动生产

1. 点击「生产模式」
2. 在右侧选择训练好的任务
3. 点击「开始生产」
4. 机械臂自动循环执行装配动作
5. 右上角实时显示产量和成功率

## 故障处理

| 故障现象 | 解决方法 |
|---------|---------|
| 机械臂不动 | 检查右上角连接状态，确认急停未按下 |
| 抓不到工件 | 点击「重新标定 → 视觉校准」 |
| 语音不识别 | 靠近麦克风(1米内)，说慢一点、大声一点 |
| 上位机卡死 | 重启 Jetson 边缘盒 |
| 产量不更新 | 点击「刷新」按钮 |

## 常见操作

- **换工件**：语音说"更换工件"或点击「切换任务」
- **调速**：语音说"速度快一点"或"慢一点"
- **看产量**：语音问"产量多少"
- **紧急停止**：按下红色急停按钮，或语音说"急停"
- **下班关机**：点击右上角设置 → 关机

## 安全须知

⚠️ 机械臂运动时，人与机械臂保持 50cm 以上安全距离
⚠️ 禁止在机械臂下方站立
⚠️ 急停按钮位于外接红色蘑菇头开关处
⚠️ 出现异常响声、抖动、碰撞时，立即按下急停
