# RoboVLA 单人+Claude Code 完整落地分步执行文档
## 文档说明
1. 定位：纯软件创业，**无任何硬件研发**，机械臂/边缘盒/相机全部外购成品
2. 人员：仅你1人，全程依靠Claude Code生成代码、排错、写脚本、做界面
3. 总周期：约2.5～3个月，分5大阶段，每阶段有明确交付物、验收标准、AI协作方法
4. 前置投入：仅硬件样机采购（遨博i5+Jetson Orin+工业相机一套），无模具/PCB/结构成本

# 单人每日标准AI协作工作流程（通用模板，每天复用）
1. **第一步：输入需求**
   把PRD对应模块要求+技术文档规范发给Claude Code；
2. **第二步：Plan规划模式**
   让AI输出分步开发计划，你审核逻辑、确认边界条件；
3. **第三步：Implement执行**
   AI批量生成代码、脚本、界面、SQL；
4. **第四步：本地真机运行测试**
   报错直接复制日志丢给AI自动修复；
5. **第五步：单元验收**
   对照文档量化指标（延迟/成功率/容错）校验；不达标让AI迭代优化；
6. **第六步：Git提交**
   AI自动生成commit注释，归档版本。

# 关键避坑分步注意事项
1. 硬件只采购成品，绝不设计PCB/结构/电机；
2. 所有AI推理强制本地Jetson运行，不依赖云端，规避网络与算力成本；
3. 模块分层严格按文档，不随意耦合，方便后续扩展机器狗插件；
4. 每完成一个模块立刻做单元测试，不要全部写完再联调；
5. 加密、授权、数据清零从一开始同步开发，不要后期补合规功能；
6. 试点工厂优先小件锁付场景，工件简单，快速跑通完整商业Demo。
